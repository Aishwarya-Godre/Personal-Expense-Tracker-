# Personal-Expense-Tracker-# Personal Expense Tracker 💰

## About the Project
Personal Expense Tracker is a beginner-friendly web project developed using HTML5. It demonstrates how users can view sample expense records and enter new expense details through an HTML form.

## Technologies Used
- HTML5

## Features
- Monthly budget summary
- Expense history table
- Expense entry form
- Expense categories
- Date and amount inputs
- Required-field validation
- Semantic HTML structure

## Project Structure
```text
personal-expense-tracker-html/
├── index.html
└── README.md
```

## How to Run
1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## HTML5 Concepts Practiced
- Semantic elements
- Forms and input types
- Tables and captions
- Labels and fieldsets
- HTML validation attributes
- Navigation links
- Meta tags

## Limitations
This is a static HTML5 prototype. Expense data is not stored, and totals are not calculated automatically.

## Future Improvements
- Add CSS3 for a professional dashboard.
- Use JavaScript to calculate expenses and update totals.
- Add filtering by category and date.
- Use Python Django and a database for persistent storage.
